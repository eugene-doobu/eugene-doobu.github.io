# Studio Icons

이 폴더에 스튜디오 가치를 표현하는 아이콘 이미지를 추가하세요.

## 필요한 아이콘 파일

1. **tech-experiment.png** (80x80px)
   - 기술 실험을 상징하는 아이콘
   - 예: 실험 플라스크, 기어, 코드 심볼 등

2. **dev-speed.png** (80x80px)
   - 개발 속도를 상징하는 아이콘
   - 예: 번개, 화살표, 시계 등

3. **light-hearted.png** (80x80px)
   - 가벼운 마음을 상징하는 아이콘
   - 예: 미소, 게임 컨트롤러, 별 등

## 파일 형식
- PNG 형식 (투명 배경 권장)
- 크기: 80x80px
- 색상: 흑백 또는 단색 (필터로 자동 조정됨)

## 현재 상태
파일이 없으면 placeholder 이미지가 표시됩니다.
